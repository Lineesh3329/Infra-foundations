# Virtual Machine (VM)

## Introduction

 - A Virtual Machine (VM) is a software-based computer that works like a real physical computer.

 - It runs inside a physical machine using virtualization technology.

 - Virtual Machine is a virtual computer created using a hypervisor.

### Components of VM

| Component        | Purpose                          |
|------------------|----------------------------------|
| vCPU             | Virtual processor for VM         |
| vRAM             | Virtual memory                   |
| Virtual Disk     | Storage for VM                   |
| Virtual NIC      | Network connection               |
| Guest OS         | Operating system inside VM       |


### Features of Virtual Machine

- Runs independently
- Supports multiple operating systems
- Isolated from other VMs
- Easy backup and restore
- Portable and scalable

### Types of Virtual Machines

| Type                | Purpose                          |
|---------------------|----------------------------------|
| System VM           | Runs complete operating system   |
| Process VM          | Runs single application/process  |

### Popular VM Tools

| Tool              | Purpose                         |
|-------------------|---------------------------------|
| VMware            | Enterprise virtualization       |
| VirtualBox        | Personal/lab virtualization     |
| Hyper-V           | Microsoft virtualization        |
| KVM               | Linux virtualization            |

### Common VM Operations

| Operation         | Purpose                         |
|-------------------|---------------------------------|
| Start             | Power on VM                     |
| Stop              | Shutdown VM                     |
| Reboot            | Restart VM                      |
| Snapshot          | Save VM state                   |
| Clone             | Create duplicate VM             |
| Migration         | Move VM to another server       |

### Advantages and Disadvantages of Virtual Machine (VM)

| Advantages                    | Disadvantages              |
|--------------------------------|----------------------------|
| Better resource utilization    | High resource usage        |
| Multiple OS in one system      | Slower than physical system |
| Isolation between VMs          | Complex management         |
| Easy backup and testing        | Needs powerful hardware    |
| Scalability                    | Host failure affects VMs  |

### VM Lifecycle

      Create VM → Configure VM → Install OS → Start VM → Monitor VM → Snapshot/Backup → Stop/Reboot VM → Delete or Migrate VM
