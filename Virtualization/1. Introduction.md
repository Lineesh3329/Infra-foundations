# Virtualization

## Introduction

Virtualization is the process of creating virtual versions of physical resources like servers, operating systems, storage, and networks using software.

It allows multiple virtual machines (VMs) to run on a single physical machine.


## Why Virtualization is Used

- Better hardware utilization
- Reduce cost
- Easy backup and recovery
- Faster server deployment
- Isolation between systems
- Supports cloud computing
- Scalability and flexibility

## Key Components

| Component      | Explanation                              |
|----------------|------------------------------------------|
| Host Machine   | Physical system where virtualization runs |
| Guest Machine  | Virtual machine running inside host      |
| Hypervisor     | Software used to create/manage VMs       |
| VM             | Virtual computer with OS and resources   |

--------------------------------------------------

## Types of Virtualization

| Type                      | Purpose                                |
|---------------------------|----------------------------------------|
| Server Virtualization     | Multiple servers on one physical server |
| Desktop Virtualization    | Virtual desktops for users             |
| Storage Virtualization    | Combine multiple storage devices       |
| Network Virtualization    | Create virtual networks                |
| Application Virtualization| Run apps separately from OS            |
| OS Virtualization         | Multiple isolated OS environments      |


## Advantages and Disadvantages of Virtualization

| Advantages                  | Disadvantages                     |
|-----------------------------|-----------------------------------|
| Better hardware utilization | Performance overhead              |
| Cost reduction              | High initial setup cost           |
| Easy backup and recovery    | Complex management                |
| Faster deployment           | Host failure affects all VMs      |
| Isolation between VMs       | Requires skilled administration   |
| Supports scalability        | Security risks if misconfigured   |
| Easy testing environment    | Resource contention may occur     |
| Reduced physical servers    | Licensing cost for some tools     |
| Efficient resource sharing  | More RAM/CPU required             |
| Supports cloud computing    | Troubleshooting can be difficult  |
--------------------------------------------------
