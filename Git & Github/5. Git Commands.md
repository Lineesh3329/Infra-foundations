# Git Commands
- Git commands are the command-line operations used to interact with the Git version control system to track changes in code and collaborate with others.
- While there are hundreds of commands, a few essential ones handle the vast majority of daily tasks.

## Repository Commands

| Command | Usage |
|---|---|
| git init | Initialize new repository |
| git clone repository_url | Copy remote repository |
| git status | Check repository status |

## Staging Commands

| Command | Usage |
|---|---|
| git add filename | Add single file to staging |
| git add . | Add all files to staging |
| git restore --staged filename | Remove file from staging |

## Commit Commands

| Command | Usage |
|---|---|
| git commit -m "message" | Save staged changes |
| git log | View commit history |
| git log --oneline | View short commit history |


## Difference & Tracking Commands

| Command | Usage |
|---|---|
| git diff | View file changes |
| git ls-files | View tracked files |


## Branch Commands

| Command | Usage |
|---|---|
| git branch branch_name | Create branch |
| git branch | View branches |
| git checkout branch_name | Switch branch |
| git checkout -b branch_name | Create and switch branch |
| git branch -d branch_name | Delete branch |
| git branch --show-current | Show current branch |



## Merge Commands

| Command | Usage |
|---|---|
| git merge branch_name | Merge branch |


## Remote Repository Commands

| Command | Usage |
|---|---|
| git remote add origin repository_url | Add remote repository |
| git remote -v | View remote repositories |
| git push origin main | Upload changes |
| git pull origin main | Download and merge changes |
| git fetch | Download changes without merge |



## Rollback Commands

| Command | Usage |
|---|---|
| git restore filename | Restore file changes |
| git reset --soft HEAD~1 | Remove commit and keep staged changes |
| git reset HEAD~1 | Remove commit and unstage changes |
| git reset --hard HEAD~1 | Remove commit permanently |
| git revert commit_id | Undo commit safely |



## File Management Commands

| Command | Usage |
|---|---|
| git rm filename | Remove file |
| git mv oldname newname | Rename file |



## Stash Commands

| Command | Usage |
|---|---|
| git stash | Temporarily save changes |
| git stash list | View stashed changes |
| git stash pop | Restore stashed changes |



## Tag Commands

| Command | Usage |
|---|---|
| git tag | View tags |
| git tag v1.0 | Create tag |


## Configuration Commands

| Command | Usage |
|---|---|
| git config --global user.name "Name" | Set username |
| git config --global user.email "email@example.com" | Set email |
| git config --list | View configuration |


## Help Commands

| Command | Usage |
|---|---|
| git help | View Git help |
| git command --help | Help for specific command |
