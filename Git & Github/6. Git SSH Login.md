# Git SSH Login
SSH (Secure Shell) is used to securely connect local system with GitHub without entering username and password every time.

- Provides secure authentication
- Uses SSH keys for login
- Commonly used with GitHub and GitLab

## Steps for Git SSH Login

### 1. Generate SSH Key

Command `ssh-keygen` used to create SSH keys, both private and public keys.

### 2. View the Public SSH Key

Command `ls .ssh` used to lists the created SSH Keys.

### 3. To view SSH public Key to GitHub

Command `cat.ssh` used to view the created SSH Keys


<img width="1042" height="85" alt="cat  ssh" src="https://github.com/user-attachments/assets/4a67592b-661a-4581-bcd6-a80edee6d815" />

### 4. Paste copied key in GitHub.
Steps:
- Open GitHub
- Go to Settings
- SSH and GPG Keys
- Click "New SSH Key"
- Paste copied key
- Save key

<img width="1158" height="432" alt="SSH key github_LI" src="https://github.com/user-attachments/assets/a48acdc6-3935-464e-86e6-3e5e5cd8da14" />

### 5. Clone Repository Using SSH

Command:
`git clone git@github.com:user/repository.git` used to clone the remote repo by using ssh links. 

Example:
git clone git@github.com:lineesh/Git-Notes.git

### Advantages of SSH Login

- More secure
- No need to enter password repeatedly
- Faster authentication
- Better for automation and DevOps

### Important Files in SSH

| File | Purpose |
|---|---|
| id_ed25519 | Private key |
| id_ed25519.pub | Public key |


### Important Note

- Never share private key
- Share only public key
- Store SSH keys securely
