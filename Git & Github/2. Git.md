# Git Introduction

## What is Git?

Git is a Distributed Version Control System (DVCS) used to track and manage changes in files and source code.

It helps developers:
- Track changes
- Work in teams
- Maintain project history
- Restore previous versions


## Evolution of Git

- Earlier, many projects used centralized systems like SVN and CVS.
- Linux kernel development needed a faster and more efficient version control system.
- Git was developed by Linus Torvalds in 2005.
- It became popular because of speed, branching, and distributed architecture.
- Today Git is the most widely used version control system.


## Features of Git

- Open-source
- Fast and lightweight
- Distributed architecture
- Offline work support
- Branching and merging
- Secure version tracking


## Advantages of Git

- Easy collaboration
- Faster operations
- Better backup
- Easy rollback
- No single point of failure


## Git Workflow

1. Working Directory  
   - Files are created or modified here.

2. Staging Area  
   - Changes are added using `git add`.

3. Local Repository  
   - Changes are saved using `git commit`.

4. Remote Repository  
   - Changes are uploaded using `git push`.


## Basic Git Flow

      Working Directory → Staging Area → Local Repository → Remote Repository

## Uses of Git

- Source code management
- Team collaboration
- DevOps projects
- CI/CD workflows
- Project tracking

## GitHub
- GitHub is a cloud-based platform that acts as a hosting service for software development projects, enabling developers to store, manage, track, and share their code.
- Built on top of the Git version control system, it allows individuals and teams to collaborate on projects, review code, and manage tasks. 

## Difference Between Git and GitHub

| Git | GitHub |
|-----|---------|
| Version control system | Cloud hosting platform |
| Works locally | Works online |
| Tracks file changes | Stores repositories |
| Can work offline | Internet required |
| Used for version management | Used for collaboration |
| Performs commit and merge | Provides pull requests and issues |
