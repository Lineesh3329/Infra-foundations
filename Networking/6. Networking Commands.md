# Networking Commands
- Networking commands are instructions used in a command-line interface (CLI) to configure, troubleshoot, and manage network settings, connectivity, and devices.
- These tools, used in Windows (Command Prompt) or Linux/macOS (Terminal), diagnose issues, monitor performance, and analyze data traffic, making them essential for network troubleshooting.



| Command    | Purpose                                     | Example                             |
| ---------- | ------------------------------------------- | ----------------------------------- |
| ping       | Checks connectivity between devices         | `ping google.com`                   |
| traceroute | Shows packet path to destination            | `traceroute google.com`             |
| ifconfig   | Displays network interface details          | `ifconfig`                          |
| ip addr    | Shows IP and interface information          | `ip addr`                           |
| netstat    | Displays network connections and ports      | `netstat -tulnp`                    |
| ss         | Shows socket statistics and listening ports | `ss -tulnp`                         |
| nslookup   | Finds IP address from domain name           | `nslookup google.com`               |
| dig        | Displays detailed DNS information           | `dig google.com`                    |
| curl       | Transfers data from server                  | `curl https://google.com`           |
| wget       | Downloads files from internet               | `wget https://example.com/file.zip` |
