# What is TCP/IP ? 

- TCP/IP stands for Transmission Control Protocol / Internet Protocol.
- It's a networking model used for communication between devices over the internet and networks.
- It defines how data is sent, received, and routed from one system to another.

## Why TCP/IP is Used

- TCP/IP provides standard method for communication between different devices and operating systems.
- It helps devices communicate reliably even if they are connected through different types of networks.

## Purpose of TCP/IP

- The main purpose of TCP/IP is to ensure proper data transmission between source and destination devices.
It handles:
          
          1. Data delivery
          2. Routing
          3. Addressing
          4. Error checking
          5. Reliable communication

TCP ensures reliable transfer, while IP handles addressing and routing.

## Where TCP/IP is Currently Used

- TCP/IP is used everywhere in modern networking and internet communication.
Examples
          
          1. Internet browsing
          2. Cloud computing
          3. Email communication
          4. Mobile applications
          5. Online gaming
          6. Video streaming
          7. AWS and cloud services
          8. Corporate networks

Whenever a device connects to the internet, TCP/IP is being used behind the scenes.


## TCP/IP Model Layers

| Layer                | Simple Definition                                  | Main Functions                                   | Protocols                        | Devices Used       | Real-time Example                |
| -------------------- | -------------------------------------------------- | ------------------------------------------------ | -------------------------------- | ------------------ | -------------------------------- |
| Application Layer    | Provides services to user applications             | Web browsing, email, file transfer, remote login | HTTP, HTTPS, FTP, SMTP, DNS, SSH | Gateway            | Opening YouTube in browser       |
| Transport Layer      | Ensures reliable communication between devices     | Segmentation, error checking, flow control       | TCP, UDP                         | Gateway            | File download using TCP          |
| Internet Layer       | Handles routing and IP addressing                  | Routing, logical addressing, packet forwarding   | IP, ICMP, ARP                    | Router             | Sending packets through internet |
| Network Access Layer | Physically transfers data through network hardware | Physical transmission, MAC addressing, framing   | Ethernet, Wi-Fi                  | Switch, Hub, Cable | Wi-Fi or Ethernet communication  |


## Difference Between OSI and TCP/IP Model

| OSI Model                                                                        | TCP/IP Model                                                |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Developed by ISO                                                                 | Developed by DoD                                            |
| 7 layers                                                                         | 4 layers                                                    |
| Theoretical model                                                                | Practical model                                             |
| Used for learning and reference                                                  | Used in real-time networking                                |
| Layers are strictly separated                                                    | Layers are loosely separated                                |
| Protocol-independent                                                             | Protocol-dependent                                          |
| Application, Presentation, and Session are separate                              | Combined into Application layer                             |
| Data Link and Physical are separate                                              | Combined into Network Access layer                          |
| Defines services, interfaces, and protocols                                      | Mainly defines protocols                                    |
| Less commonly used in implementation                                             | Widely used in internet communication                       |
| Network layer supports both connection-oriented and connectionless communication | Internet layer mainly supports connectionless communication |

## Note:
1. OSI model is mainly used for understanding networking concepts.
2. TCP/IP model is used in real-world internet communication.
