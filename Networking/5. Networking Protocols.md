# Networking Protocols

- Networking protocols are simply a set of rules that allow digital devices to communicate with each other
Protocols define:

        * How data is sent
        * How data is received
        * How devices communicate

- Without protocols, devices cannot understand each other.

Different protocols handle different parts of the communication process. Here are the most common ones explained simply: 

## Networking Protocols:
| Protocol | Name                                | Purpose                      | Port Number |
| -------- | ----------------------------------- | ---------------------------- | ----------- |
| HTTP     | HyperText Transfer Protocol         | Access websites              | 80          |
| HTTPS    | HyperText Transfer Protocol Secure  | Secure website communication | 443         |
| FTP      | File Transfer Protocol              | File transfer                | 21          |
| SFTP     | Secure File Transfer Protocol       | Secure file transfer         | 22          |
| SSH      | Secure Shell                        | Remote login/access          | 22          |
| DNS      | Domain Name System                  | Converts domain to IP        | 53          |
| DHCP     | Dynamic Host Configuration Protocol | Assigns IP addresses         | 67/68       |
| SMTP     | Simple Mail Transfer Protocol       | Sending emails               | 25          |
| POP3     | Post Office Protocol v3             | Receiving emails             | 110         |
| IMAP     | Internet Message Access Protocol    | Access emails from server    | 143         |
| SNMP     | Simple Network Management Protocol  | Network monitoring           | 161         |
| ICMP     | Internet Control Message Protocol   | Error checking and ping      | No port     |
| Telnet   | Teletype Network                    | Remote access (not secure)   | 23          |
| IP       | Internet Protocol             | Handles addressing and routing of packets | No port number    |
| TCP      | Transmission Control Protocol | Reliable data transmission                | Uses port numbers |
| UDP      | User Datagram Protocol        | Fast data transmission                    | Uses port numbers |


## HTTP — Port 80
- HTTP stands for HyperText Transfer Protocol.
- It is used to open and access websites on the internet.
- It is not secure because data is transferred in plain text.
Example:
- Opening normal websites.

## HTTPS — Port 443
- HTTPS stands for HyperText Transfer Protocol Secure.
- It is the secure version of HTTP.
- Uses SSL/TLS encryption for safe communication.
#### Example:
-Online banking, Gmail login.

## FTP — Port 21
- FTP stands for File Transfer Protocol.
- Used for transferring files between systems over network.
#### Example:
- Uploading website files to server.

## SFTP — Port 22
- SFTP stands for Secure File Transfer Protocol.
- Used for secure file transfer using SSH encryption.
#### Example:
- Secure backup transfer.

## SSH — Port 22
- SSH stands for Secure Shell.
- Used to remotely access Linux servers securely.
#### Example:
- Connecting to AWS EC2 Linux server.

## DNS — Port 53
- DNS stands for Domain Name System.
- Converts domain names into IP addresses.
#### Example:
- google.com → IP address.

## DHCP — Port 67/68
- DHCP stands for Dynamic Host Configuration Protocol.
- Automatically assigns IP addresses to devices.
#### Example:
- Wi-Fi router giving IP to laptop.

## SMTP — Port 25
- SMTP stands for Simple Mail Transfer Protocol.
- Used for sending emails.
#### Example:
- Sending mail through Gmail.

## POP3 — Port 110
- POP3 stands for Post Office Protocol version 3.
- Used for downloading emails from mail server.
#### Example:
- Emails stored locally on device.

## IMAP — Port 143
- IMAP stands for Internet Message Access Protocol.
- Used for accessing emails directly from server.
#### Example:
- Same email visible on mobile and laptop.

## SNMP — Port 161
- SNMP stands for Simple Network Management Protocol.
- Used for monitoring network devices.
#### Example:
- Monitoring routers and switches.

## ICMP — No Port Number
- ICMP stands for Internet Control Message Protocol.
- Used for network checking and error reporting.
#### Example:
- ping command.

## Telnet — Port 23
- Telnet is used for remote access to systems.
- It is not secure because data is not encrypted.
#### Example:
- Old remote server access.

## IP — No Port Number
- IP stands for Internet Protocol.
- Responsible for addressing and routing packets between networks.
#### Example:
- Sending packet from one network to another.

## TCP — Uses Port Numbers
- TCP stands for Transmission Control Protocol.
- Provides reliable communication with error checking.
#### Example:
- Website loading, file download.
#### Common Ports:

          HTTP → 80
          HTTPS → 443
          SSH → 22
          FTP → 21
          SMTP → 25

## UDP — Uses Port Numbers
- UDP stands for User Datagram Protocol.
- Provides faster communication with less reliability.
#### Example:
Gaming, video streaming, voice calls.

#### Common Ports:

          DNS → 53
          DHCP → 67/68
          SNMP → 161
