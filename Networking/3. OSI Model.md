# OSI Model 
- OSI stands for Open Systems Interconnection.
- It is a reference model used to understand how data travels from one device to another in a network.
- The OSI model divides network communication into 7 layers.
- Each layer performs a specific function.

Why OSI Model is Necessary
-
The OSI model is important because:
| Purpose          | Explanation                                    |
| ---------------- | ---------------------------------------------- |
| Standardization  | Provides common networking standards           |
| Troubleshooting  | Helps identify network problems layer by layer |
| Easy Learning    | Simplifies networking concepts                 |
| Interoperability | Different devices/vendors can communicate      |
| Modularity       | Each layer works independently                 |

OSI Layers Table
-
The data passes through each layers to provide final outcome efficiently.

| Layer Number | Layer Name   | Main Function                      | Device     |
| ------------ | ------------ | ---------------------------------- |------------|
| 7            | Application  | User interaction                   | Gateway    |
| 6            | Presentation | Data formatting & encryption       | Gateway    |
| 5            | Session      | Establishes communication sessions | Gateway    |
| 4            | Transport    | Reliable data transfer             | Gateway    |
| 3            | Network      | Routing and IP addressing          | Router     |
| 2            | Data Link    | MAC addressing and framing         | Switch     |
| 1            | Physical     | Transmission of bits               | Hub/Cables |





1.Application Layer
-
- This layer is the closest layer to the user.
- It allows users to access network services like websites, emails, and file sharing.
- It uses protocols like HTTP, HTTPS, FTP, SMTP, DNS

#### What it Does
1. Opens websites
2. Sends emails
3. Transfers files
4. Provides communication between user applications and network

#### Real-time Example

      When you open YouTube in Chrome:
      Browser sends request through Application layer.
      
      User → Browser/App → Application Layer

2.Presentation Layer
-
- This layer converts data into readable format.
- Acts like a translator between systems.

#### What it Does
1. Encrypts data
2. Decrypts data
3. Compresses data
4. Converts formats

#### Real-time Example

        When using HTTPS websites:
        Data is encrypted here.
        
        Original Data ↔ Converted/Encrypted Data

3.Session Layer
-
This layer creates and manages connection sessions between devices.

#### What it Does
1. Starts session
2. Maintains session
3. Ends session

#### Real-time Example

            When attending Google Meet:
            Session remains active until meeting ends.
            
            Start Session → Maintain → End Session

4.Transport Layer
-
- This layer ensures data reaches correctly and completely.
- Protocols used TCP, UDP

#### What it Does
1. Breaks data into segments
2. Error checking
3. Controls data flow
4. Reliable communication

         Large Data → Small Segments → Sent Safely

5.Network Layer
-

- This layer finds the best path for data.
- Protocols used IP, ICMP and uses IP addresses.
- Device used Router.

#### What it Does
1. Routing
2. IP addressing
3. Path selection

#### Real-time Example
      Router sending internet packets from your home to Google server.
      
      Source IP → Router → Destination IP

6.Data Link Layer
-
- This layer transfers data inside the same network.
- Uses MAC addresses.
- Device used Switch 

#### What it Does
1. Framing
2. MAC addressing
3. Error detection
4. Device Used
5. Switch

#### Real-time Example

        Switch sends data to correct computer in office LAN.
        
        Switch → Uses MAC Address → Sends Data
7.Physical Layer
-
This layer physically sends data through cables or signals.
Used Devices are Ethernet cable, Hub, Repeater

#### What it Does
1.Transfers bits
2.Electrical signals
3.Physical connection

#### Real-time Example

      Internet cable carrying signals between router and PC.

      101010 Bits → Cable → Destination
