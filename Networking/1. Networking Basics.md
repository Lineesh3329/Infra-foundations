# Introduction
Computer networking is the process of connecting multiple computers and devices together to share data, resources, and communication.
Example:
- Sharing files 
- Internet access
- Sending emails
- Video calls

 Networking
 --
A computer network is a system of interconnected computing devices (hosts) that share resources, data, and applications via wired (cables) or wireless (radio waves) connections.

It helps devices:

- Exchange data
- Access the internet
- Share printers and files
- Communicate securely

#### Real-time Example
When our mobile connects to Wi-Fi and accesses YouTube, networking is happening between:
       
        *Mobile
        *Router
        *Internet server

Networking Components
-
Network components are the physical hardware and software protocols that enable computers and devices to connect, share data, and communicate.

| Component          | Purpose                       |
| ------------------ | ----------------------------- |
| Sender             | Device sending data           |
| Receiver           | Device receiving data         |
| Transmission Media | Path used to transfer data    |
| Protocol           | Rules for communication       |
| IP Address         | Identifies devices in network |

Transmission Media Types
-
Transmission media are the physical pathways or wireless channels used to carry information from a sender to a receiver in a network.

1. Wired

   - Ethernet Cable
   - Fiber Optic
3. Wireless

   - Wi-Fi
   - Bluetooth
  
Networking Devices
-
The physical hardware components that enable computers and other devices to connect, communicate, and share data over a network.

| Device       | Purpose                              | Example              |
| ------------ | ------------------------------------ |----------------------|
| Router       | Connects different networks          |  Home Wifi router    |
| Switch       | Connects devices within same network |  LAN- 8-port switch  |
| Hub          | Broadcasts data to all devices       |  8-port Ethernet Hub |
| Modem        | Connects network to internet (ISP)   |  Broadband modem     |
| Firewall     | Protects network from threats        |  NGFW                |
| Access Point | Provides wireless connectivity       |  Wifi, Bluetooth     |

           Example:
           Internet → Modem → Router → Switch → Computers

Networking Topologies
-
Network topology means the physical or logical arrangement of devices in a network.

| Topology | Description                             |
| -------- | --------------------------------------- |
| Star     | All devices connected to central switch |
| Bus      | Single backbone cable used              |
| Ring     | Devices connected in circular form      |
| Mesh     | Every device connected to each other    |


Star Topology
-
- Most commonly used topology
- Easy to manage
- Uses switch/hub as center point

             PC1
              |
       PC2 -- Switch -- PC3
              |
             PC4

Bus Topology
-
- Single cable connects all devices
- Cheap but difficult to troubleshoot

        PC1 ---- PC2 ---- PC3 ---- PC4

Ring Topology
-
- Devices connected in circular path
- Data travels in one direction

           PC1 ------ PC2
            |          |
            |          |
           PC4 ------ PC3

Mesh Topology
-
- Each device connected to all devices
- Highly reliable
- Expensive

                 PC1
                / | \
               /  |  \
             PC2--|--PC3
               \  |  /
                \ | /
                 PC4

Tree Topology
-
- Hierarchical structure
- Combination of star and bus topology
- Scalable for large networks
- Backbone cable failure affects network, High cost

                        Main Switch
                             |
                   -------------------
                   |                 |
                Switch1          Switch2
                 /   \             /   \
               PC1   PC2        PC3   PC4
