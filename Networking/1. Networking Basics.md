# Introduction
Computer networking is the process of connecting multiple computers and devices together to share data, resources, and communication.
Example:
- Sharing files 
- Internet access
- Sending emails
- Video calls

 Networking
 --
A computer network is a system of interconnected computing devices (hosts) that share resources, data, and applications via wired (cables) or wireless (radio waves) connections.

It helps devices:

- Exchange data
- Access the internet
- Share printers and files
- Communicate securely

#### Real-time Example
When our mobile connects to Wi-Fi and accesses YouTube, networking is happening between:
       
        *Mobile
        *Router
        *Internet server

Networking Components
-
Network components are the physical hardware and software protocols that enable computers and devices to connect, share data, and communicate.

| Component          | Purpose                       |
| ------------------ | ----------------------------- |
| Sender             | Device sending data           |
| Receiver           | Device receiving data         |
| Transmission Media | Path used to transfer data    |
| Protocol           | Rules for communication       |
| IP Address         | Identifies devices in network |

Transmission Media Types
-
1. Wired

   - Ethernet Cable
   - Fiber Optic
3. Wireless

   - Wi-Fi
   - Bluetooth
