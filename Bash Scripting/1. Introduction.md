# Bash Scripting

Bourne-Again-shell a command line interpreter used in Linux. Bash scripting is the process of writing a sequence of Linux commands in a file to automate tasks by running it as program.

### Why Bash Scripting?
---
- Automates repetitive tasks
- Saves time and effort
- Reduces manual errors
- Widely used in DevOps and system administration

### Where is it used?
---
- System administration (user management, disk monitoring)
- Application deployment
- Backup and scheduling
- Log monitoring and troubleshooting
