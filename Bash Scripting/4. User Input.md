# User Input
- User Input is taking data from the user while script is running.
- In Bash we use `read` command.

On this basis, it has three derived commands,
1. `read -p`   - Prompt, -p allows inline prompt
2. `read -sp`  - Hides input, used for Password entity
3. `read -t`   - It exits if no entry found within 5 seconds

- Basically used in Automation scripts, Ci/Cd, Login scripts and for security purposes.
