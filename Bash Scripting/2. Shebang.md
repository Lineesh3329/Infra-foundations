
# Shebang
Shebang (#!) is a special character sequence placed at the very beginning of a script file.  
It tells the operating system which interpreter should be used to execute the script.

Example:
---
      #!/bin/bash         - Use Bash
      #!/bin/bash         - Bash shell
      #!/bin/sh           - Default shell
      #!/usr/bin/python3  - Python 3
      #!/usr/bin/env bash - Bash from environment path

## Why is Shebang Needed ?
When we run a script, the system needs to know:
Which shell or interpreter should execute it

Without shebang:
The system may not know how to run the script
You must manually specify the interpreter

With shebang:
Script runs directly without specifying interpreter

## How Shebang Works
When we execute:

            #!/bin/bash
            echo "Hello Lineesh"
The OS:

1. Reads the first line of the file
2. Detects the shebang (#!)
3. Uses the specified interpreter
4. Executes the script using that interpreter

## Note:
            chmod +x filescript.sh   used to give executable access to the script
            ./filescript.sh          used to run the script

## Advantages of Shebang
1. Makes script executable directly
2. Defines interpreter clearly
3. Improves portability
4. Avoids ambiguity between shells
5. Useful in automation and DevOps
