
# Shebang
Shebang (#!) is a special character sequence placed at the very beginning of a script file.  
It tells the operating system which interpreter should be used to execute the script.

Example:
---
      #!/bin/bash         - Use Bash
      #!/bin/bash         - Bash shell
      #!/bin/sh           - Default shell
      #!/usr/bin/python3  - Python 3
      #!/usr/bin/env bash - Bash from environment path

## Why is Shebang Needed ?
When we run a script, the system needs to know:
Which shell or interpreter should execute it

Without shebang:
The system may not know how to run the script
You must manually specify the interpreter

With shebang:
Script runs directly without specifying interpreter
