# Conditinal Statement
A Conditional statement in Bash is used to make decisions and execute code based on weather a condition is true or false.


If Statement
---
- If statement is used to check a condition and execute code based on true or fale.

- In Bash scripting value 0= True; value 1= False.

- `if` is start and `fi` is end of the syntax.

- Note: space to be there to and fro of the [ ]. 

#### Syntax
        if [ condition ]
        then
            commands
         fi


If-Else Statement:
----

        if [ condition ]
        then
          commands
        else
          commands
        fi

If-Elif-Else Statement:
--

      if [ condition1 ]
      then
           command_1
      elif [ condition2 ]
           then
           command_2
      else
           command_3
      fi


Nested IF
--

       if [ $num -gt 0 ]
       then
           if [ $num -lt 100 ]
           then
           echo "Between 1 and 99"
           fi
       fi

       
String Comparisons
-

| Operator | Description |
|----------|----------|
| `=` | Equal |
| `!=` | Not equal |
| `-z` | String is empty |
| `-n` | String is not empty |



Numeric Comparisons
-

| Operator | Description |
|----------|----------|
| `-eq` | Equal |
| `-ne` | Not equal |
| `-gt` | Greater than |
| `-lt` | Less than |
| `-ge` | Greater than or equal |
| `-le` | Less than or equal |



Logical Operators
-

| Operator | Description |
|----------|----------|
| `&&` | AND |
| `||` | OR |
| `!` | NOT |


File Conditions
-

| Condition | Description |
|-----------|----------|
| `-f` | File exists |
| `-d` | Directory exists |
| `-r` | Read Permission |
| `-w` | Write Permission |
| `-x` | Execute Permission |
