Variable
---------
- A Bash variable is name that stores a value for reuse in a script.
- The value can be string, number or command output.
- This is temporary storage memory.

## Accessing Variable
      1. SKILL="DevOps"           2. PACKAGE="httpd wget unzip"
         echo $SKILL                 yum install $PACKAGE -Y
- No spaces around =.
- $ used to get the assigned value of variable.

## Command Line Arguments
- These are values passed to a script when we run it fromm the terminal.
- Used in scripts like Deployment,Backup, Automation tools

     |   Variable    |    Description   |
     |---------------|------------------|
     | `$0'         | Script name |
     | `$1,$2....$9` | Argument passed to the script |
     | `$#`         | Number of Arguments |
     | `$@`          | All Arguments |
     | `$*`         | All arguments (single strings) |
     | `$?`         | Exit status / Recent run process (0 = success, non-zero = error) |
     | `$Hostname`         | Prints Hostname |
     | `$User`         | Prints Username |
     | `$Random`         | Prints Random Number |           
     |  `$Home` | Displays the current user's home directory. |
     |  `$Pwd` | Displays the present working directory |
     |  `$Path` | Shows the executable search path  |
     |  `$Seconds` | Shows the number of seconds since the script running |
     |  `$Lineno` | Shows the current line number |
