# Variable

- A Bash variable is name that stores a value for reuse in a script.
- The value can be string, number or command output.
- This is temporary storage memory.

## Accessing Variable
      1. SKILL="DevOps"           2. PACKAGE="httpd wget unzip"
         echo $SKILL                 yum install $PACKAGE -Y
- No spaces around =.
- $ used to get the assigned value of variable.

## Command Line Arguments
- These are values passed to a script when we run it fromm the terminal.
- Used in scripts like Deployment,Backup, Automation tools

     |   Variable    |    Description   |
     |---------------|------------------|
     | `$0`        | Script name |
     | `$1,$2....$9` | Argument passed to the script |
     | `$#`         | Number of Arguments |
     | `$@`          | All Arguments |
     | `$*`         | All arguments (single strings) |
     | `$?`         | Exit status / Recent run process (0 = success, non-zero = error) |
     | `$HOSTNAME`         | Prints Hostname |
     | `$USER`         | Prints Username |
     | `$RANDOM`         | Prints Random Number |           
     |  `$HOME` | Displays the current user's home directory. |
     |  `$PWD` | Displays the present working directory |
     |  `$PATH` | Shows the executable search path  |
     |  `$SECONDS` | Shows the number of seconds since the script running |
     |  `$LINENO` | Shows the current line number |

## Quotes
- Quotes used to control bash interprets text/variable.
- They classified into

              1. Double Quotes ""   --> Used when variables needed
              2. Single Quotes ''   --> Used when text needed

- Double Quotes allows variable expansion and command substitution
- Single Quotes treat everything as literal text in Bash

## Exporting Variables
- Usually created variable in Bash is local in that particular shell session. If we exit the session, created variables fades. So inorder to make it available to child process- sub-shells we need to export into a global variable.

              Syntax : export VariableName=Value
- For Root user, the variable is stored in the hidden file `.basharc`
- For Every users, the variable is stored in `/etc/profile.basharc`

                  ~/.profile      - Specific user  
                  ~/.basharc      - Specific user
                   /etc/profile   - Everyone
                  env or printenv - Shows exported (child shell) variables.
