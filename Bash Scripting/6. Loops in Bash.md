# Loops

- A Loop is a control structure used to execute a block of code repeatedly until a condition is met

- This repeats commands multiple times automatically. 

1.For Loop
---

- For Loop iterates over a list of values and executes commands for each value.

            for i in list
            do
                 commands
            done

2.While Loop 
-

- While loop runs a block of code repeatedly as long as the condition is true.
- If condition is true run commands until it becomes false.
- `sleep` is used to pauses for certain time and then continue the loop. eg: `sleep 10`
- `sleep` helps for sheduling taks.
  
            while [ condition ]
            do
                commands
            done
            sleep #(optional)

3.Until Loop 
-

 - Until Loop runs commands repeatedly until the condition becomes true (opposite to while loop).

            until [ condition ]
            do
                commands
            done

Loop Control Statements
-

- `break`    - Break helps to stops loop completely.

- `continue` - Continue helps to skip the current iteration.

Loop Use cases
-
1. Creating multiple users
2. Process log files
3. Checking multiple servers
4. Deploy multiple environments
5. Automatic repetitive tasks
